# Requisitos para o Rule34 Downloader

Este script automatiza o download de imagens e vídeos do Rule34 usando a API oficial.

## 1. Dependências do Sistema
- **Python 3.x**: O script foi escrito para Python 3.
- **Bibliotecas Necessárias**:
  - `requests`: Para fazer as requisições HTTP.
  - `python-dotenv`: Para carregar as credenciais do arquivo `.env`.
  Instalação: `pip install requests python-dotenv`

## 2. Arquivos (Opcionais)
- **.env**: Local recomendado para suas credenciais (`R34_API_KEY` e `R34_USER_ID`). O script cria este arquivo se você usar o setup interativo.
- **disgustingthings-aka-blacklist.txt**: Se existir, conterá as tags bloqueadas separadas por espaços simples. O script as ignora automaticamente em todas as buscas.

## 3. Como Executar
Você pode executar o script de duas formas:

### A. Modo Interativo (Simples)
Basta rodar o script e seguir as instruções na tela:
`python3 rule34_downloader.py`

### B. Modo via Terminal (Rápido)
Passe as tags diretamente como argumentos:
`python3 rule34_downloader.py "cat_ears high_res"`

## 4. Novas Funcionalidades
- **Setup Interativo (.env)**: O script ajuda a configurar suas credenciais no primeiro uso se não encontrar as variáveis de ambiente.
- **Entrada de Tags Flexível**: Se você esquecer de passar as tags via terminal, o script perguntará quais deseja baixar.
- **Multithreading**: Baixa até 10 arquivos simultaneamente.
- **Verificação de Duplicatas**: Pula arquivos já baixados na pasta `downloads/`.

## 5. Dicas de Uso
- Para ver seu ID e Chave API, acesse: [https://rule34.xxx/index.php?page=account&s=options](https://rule34.xxx/index.php?page=account&s=options)
- Use `Ctrl+C` a qualquer momento para cancelar o download com segurança.
